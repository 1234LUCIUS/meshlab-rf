# MeshLab RF

**Simulateur simple de réseaux radio LoRa pour Meshtastic et MeshCore.**

Placez quelques nœuds sur une carte, lancez la simulation et voyez immédiatement quelles liaisons fonctionnent.

## Télécharger

**[Télécharger MeshLab RF (.zip)](https://github.com/1234LUCIUS/meshlab-rf/releases/latest/download/meshlab-rf.zip)**

## Démarrer en 3 étapes

1. Décompressez le fichier `.zip`.
2. Lancez le fichier adapté à votre ordinateur :
   - **Windows :** double-cliquez sur `start.bat`
   - **Linux / macOS :** lancez `./start.sh`
3. Ouvrez **[http://localhost:8765](http://localhost:8765)**.

> Il faut seulement **Node.js 18 ou plus récent**. Aucune installation de dépendance n’est nécessaire.

## À quoi ça sert ?

- tester une implantation de nœuds avant une installation réelle ;
- comparer **Meshtastic** et **MeshCore** ;
- visualiser les liaisons radio, le relief, la végétation et le bâti ;
- observer les messages, relais, collisions et pertes ;
- ajuster les antennes, la puissance et les paramètres radio.

## Pour commencer

- **Débutant :** ouvrez l’outil, choisissez le protocole, ajoutez des nœuds sur la carte et cliquez sur **Simulateur**.
- **Professionnel :** utilisez les réglages radio, le terrain, le trafic, le Dashboard et le bilan détaillé de chaque liaison.
